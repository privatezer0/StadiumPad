# Contributing

Fork the repository, make a focused change and open a pull request. Public access
does not grant write access to the upstream repository. Maintainers review merges.

For bugs, include app/firmware version, reproduction steps, expected result and
actual result. Redact personal preset names/data, addresses, identifiers and
credentials from screenshots and reports. Never attach raw private captures by default.

Read README_AI.md and AGENTS.md, preserve unknown native preset data, and add tests
for meaningful behavioral changes. Run the documented Swift and loopback checks.
Hardware tests need explicit permission and new spare copies only. Describe what
was actually tested, separating simulated, native-layout and physical-device results.

Keep criticism specific and useful. Reports, patches and thoughtful design feedback
help more than labels. AI-assisted contributions receive the same correctness,
maintainability and review standards as any other contribution.
