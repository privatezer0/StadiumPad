# Security and privacy

StadiumPad connects directly to a selected Stadium on the local network. It does
not embed a cloud service, transfer credentials or analytics. Use the device's
supported Remote Access configuration; this app does not bypass access controls.

Do not commit or publicly attach presets, raw captures, device identifiers, private
addresses, signing keys/profiles or tokens. Backups under the app's Documents folder
contain user data. Extracted editor metadata is locally generated and Git-ignored.

Report a security issue privately to the repository owner using GitHub's private
security reporting if available; otherwise contact the maintainer privately first.
Do not publish credentials or a user's private data in a public issue.

Only maintainers receive upstream write access. Contributors use forks and pull
requests. No contributor write access is granted by making this repository public.
